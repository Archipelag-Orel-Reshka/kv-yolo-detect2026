# kv-yolo-detect2026

Конвейер, USB-камера и подсчёт деталей для прикладной робототехники
на региональном этапе «Новая высота 2026», Владимир.

[Конкурсное ТЗ](docs/README.md) описывает требования и оценивание.
[Работа с прошивкой](firmware/README.md) описывает сборку, загрузку и USB-команды.
[Проверка оборудования](docs/hardware-check.md) фиксирует результат проверки на площадке.
[Подготовка датасета](docs/dataset.md) описывает 50 изображений для загрузки в Roboflow.

## Структура

```text
firmware/conveyor_controller/  прошивка DXL-IoT, мотор ID 22
firmware/libraries/            библиотека производителя, закреплённая версия
tools/                        сборка, загрузка и управление с ноутбука
docs/                         ТЗ и протокол обмена
backend/                      будущий сервер камеры, детектора и отчётов
frontend/                     будущая веб-панель
dataset/                      исходные фотографии команды
dataset/roboflow-upload/       50 изображений, train/valid/test
models/                       веса YOLO11n и обученной модели
reports/                      автоматически сохранённые отчёты
tests/                        проверки протокола и защит прошивки
```

Сейчас реализуется управление лентой. Веб-панель, детектор, счётчики
и автоматические отчёты ещё не реализованы. Датасет собирает команда.
Готовый `yolo11n.pt` обучен на COCO; для трёх конкурсных деталей понадобятся
свои размеченные фотографии и обученные веса.

## Оборудование

На фото контроллер соответствует DXL-IoT с Ethernet/microSD расширением.
Основная плата программируется как Arduino Mega 2560, ATmega2560, 16 МГц.
Мотор подключён к встроенной шине Dynamixel, адрес 22.
На площадке диагностикой подтверждён MX-64, номер модели 310,
протокол 1.0, скорость шины 1000000 бод, ID 22.
USB на ноутбуке: CH340, `/dev/serial/by-id/usb-1a86_USB_Serial-if00-port0`.
Внешняя камера: Logitech C510.

Ethernet-расширение для связи по USB не требуется. Прошивка его не использует.
USB питает логику платы; питание мотора должно соответствовать его модели.
