# Фотографии для Roboflow

Готовые изображения: `dataset/roboflow-upload/`.
Архив тех же изображений: `dataset/roboflow-upload.zip`.
Исходные фотографии в корне `dataset/` сохранены без изменений.

Из 26 исходных файлов выделены 13 снимков с уникальными пикселями.
На их основе подготовлены ровно 50 изображений: 13 оригиналов и
37 вариантов яркости, контраста и насыщенности. Размер кадра, положение
деталей и геометрия сохранены. Координаты будущих bounding boxes совпадают
с координатами исходника. Метки классов и рамки пока не созданы.

## Загрузка и разметка

В Roboflow создай проект Object Detection. Загрузи только готовый набор,
не добавляй к нему ещё раз исходные фотографии из корня `dataset/`.
Подпапки определяют подготовленные выборки:

| Выборка | Изображения | Что внутри |
| --- | ---: | --- |
| train | 44 | 7 исходных кадров и 37 вариантов |
| valid | 3 | Отдельные исходные снимки без вариантов |
| test | 3 | Ещё три исходных снимка без вариантов |

Загрузи подпапки отдельными партиями и сохрани их назначение при
распределении выборок. Не запускай случайное перераспределение всех
50 файлов: варианты одного кадра должны остаться в одной выборке.
Группа исходника указана префиксом `g01`, `g02` и т.д. в имени файла.
Полная связь с исходниками есть в `dataset/roboflow-manifest.csv`.

Размечай все видимые детали, включая изображения с несколькими деталями.
Используй согласованные классы `small`, `medium`, `large`.
На зачёте детали идут по одной, но изображения с несколькими деталями
тоже можно использовать для детектора, если каждая имеет свою рамку.
Частично видимые детали также должны иметь рамки по принятому правилу
разметки. У некоторых исходников деталь обрезана краем кадра.

Все 50 файлов проверены по декодированным RGB-пикселям и отличаются друг
от друга. Успешная загрузка в Roboflow пока не проверена.
Roboflow [пропускает точные дубли при загрузке](https://docs.roboflow.com/adding-data/object-detection).
Смена имени или EXIF сама по себе не добавляет нового изображения.

Это 13 уникальных исходных кадров, а не 50 независимых наблюдений.
По трём снимкам в valid/test можно проверить первый запуск, но такую
оценку качества не стоит считать окончательной. Для следующего набора
сними новые положения и повороты каждого вида на ленте, а также пустую
ленту. Пустые кадры добавляются без рамок.

## Воспроизведение

```bash
uv pip install --python .venv/bin/python -r requirements-dataset.txt
.venv/bin/python tools/prepare_dataset.py --source dataset --count 50
```

Скрипт не перезаписывает существующий результат. Для повторной подготовки
используй другую папку с исходниками. Группы valid `5,8,12` и test `4,6,9`
выбраны после просмотра текущих снимков. На другом наборе их нужно выбрать
заново через `--valid-groups` и `--test-groups`.
