# Проверка на площадке, 14 октября 2026

Фото соответствует сборке DXL-IoT с Ethernet/microSD расширением.
Ноутбук видит CH340 `1a86:7523`, `/dev/ttyUSB0`.

Первое подключение вело к встроенному ESP32:

```text
ets Jun 8 2016 00:22:57
boot:0x17 (SPI_FAST_FLASH_BOOT)
ESP-IDF v4.0.1
```

Чтение через загрузчик Mega завершилось `stk500v2_getsync() failed`.
Flash/EEPROM не прочитаны, новая прошивка не записана.
Нужно переставить USB в порт основного ATmega2560 и повторить проверку.
После подключения ожидается сигнатура ATmega2560 `0x1e9801`.

Права на первое подключение получены через временное ACL. При смене
USB-порта ACL может понадобиться установить повторно.

Сборка прошивки проходит, использует 11302 байта flash и 1374 байта RAM.
Предупреждения компилятора находятся в библиотеке производителя.
Нативные тесты проверяют разрешение запуска, кодирование направления,
таймаут связи, поздний heartbeat, отказ записи, повтор остановки,
переполнение строки и отказ управления неизвестной моделью.

Модель мотора ID 22, связь по Dynamixel и физическое движение пока
не подтверждены. Сборка и тесты на ноутбуке этого не доказывают.
