# Библиотека производителя

`DxlMaster2` взята без изменений из
[AppliedRobotics/dxlmaster2](https://github.com/AppliedRobotics/dxlmaster2),
commit `cb16d3c7c63c1b4ace201886ccb346f50e9caf55`.
Лицензия сохранена в `DxlMaster2/LICENSE`.

На ATmega2560 библиотека использует `Serial1`, TX-enable D42 и RX-enable D43.
USB-команды приложения идут через отдельный `Serial`.
Эта разводка предназначена для DXL-IoT, а не обычной Mega без трансивера.

В приложении используются низкоуровневые чтения и записи с проверкой
регистра после записи. Методы `model()` и `init()` этой версии библиотеки
используют адреса Protocol 1.0 даже для Protocol 2.0, поэтому приложение
не вызывает их. `speed()` Protocol 1.0 не кодирует отрицательное направление;
приложение формирует бит направления самостоятельно.

Запись скалярного значения вызывается только с явным типом
`DxlMaster.write<T>(protocol, id, address, value, 0)`.
Без `<T>` сочетание `uint16_t value` и литерала `0` выбирает перегрузку
записи буфера: значение становится длиной, а `0` становится указателем.
В результате команда скорости передаёт неверные данные. Нативный тест
содержит обе перегрузки API и проверяет, что прошивка вызывает нужную.
